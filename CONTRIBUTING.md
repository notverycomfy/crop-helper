# Contributing to Crop Helper

Thanks for helping improve Crop Helper. Search existing issues before opening a new one, and keep each report focused on one problem or suggestion.

## Bug reports

Include the Minecraft and loader versions, the configuration being used, a clear description of the problem, and steps to reproduce it. Attach the latest log when relevant. Screenshots are useful for incorrect outlines, colors, or crop detection.

## Code changes

1. Create a branch from the supported-version branch affected by the change.
2. Keep changes focused and preserve the existing client-side behavior.
3. Run `./gradlew build` before submitting a pull request.
4. Explain what changed and how it was tested in game.

Do not include generated build output, game saves, logs, or redistributed third-party assets.
